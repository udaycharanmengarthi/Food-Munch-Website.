> **Eat Bold. Live Loud.** — A modern food delivery website built with HTML & CSS.

---

## ✨ Features

- 🎨 Bold, modern UI with warm editorial design
- 📱 Fully responsive — mobile, tablet & desktop
- 🖱️ Custom animated cursor
- 🍽️ Interactive menu with filterable dish cards
- 🎬 Smooth scroll reveal animations
- ⭐ Testimonials & newsletter section

---

## 🛠️ Tech Stack

- **HTML5** — structure & semantics
- **CSS3** — animations, Flexbox, Grid
- **Vanilla JS** — interactions & effects

---

## 🚀 Run Locally

```bash
git clone https://github.com/udaycharanmengarthi/food-munch-website.git
cd food-munch-website
open index.html
```
